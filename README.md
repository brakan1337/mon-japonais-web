# Mon japonais — version web

**En ligne : https://brakan1337.github.io/mon-japonais-web/**

Ce dépôt ne contient que le **site déjà construit**, jamais le code source.
Celui-ci vit dans le dépôt privé `brakan1337/mon-japonais` et se republie avec
`npm run publier-web`.

Entraînement au japonais en romaji, A1 à B1 : phrases à construire en
étiquettes, conversations, les deux sens de traduction.

**Aucune connexion, et la progression ne se garde pas.** Elle vit le temps de
l.onglet et repart à zéro à chaque visite — c.est assumé : ça supprime d.un
coup le stockage du navigateur et tous ses cas limites. Pour une progression
qui dure, c.est l.application Android qu.il faut.
